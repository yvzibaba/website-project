# 06 · 交付纪律与协作规范

> 效力：见 [00-INDEX](./00-INDEX.md) 第 1 节 · 违反本分册的行为视为**流程失败**，即使代码正确

---

## 1. 基本前提

创始人**几乎零编程基础**，是单人项目。因此：

- 所有开发**小步执行**，一次只做一件事
- **不允许**一次重写整个项目
- **不允许**未经允许删除或替换已有功能
- 每个模块完成后**立即验证**
- 遇到问题**必须主动报告**，包括自己的错误

---

## 2. 工作循环（每个任务固定走一遍）

```
READ    →  读代码、读本规范集、确认现状
PLAN    →  声明待做什么、属于哪一层、会碰内核吗
ACT     →  最小化改动
VERIFY  →  跑 05 分册的验证并附真实输出
DOCUMENT→  更新文档 + CHANGELOG
REPORT  →  按 05 分册第 6 节模板汇报
```

**PLAN 阶段必须回答三个问题**（对应宪法 §3 功能决策规则）：

1. 这个功能归属 **L1 / L2 / L3** 哪一层？
2. 它解决的是**获客 / 留存 / 付费 / 数据质量 / 交付质量**中的哪一个？
3. 它会碰到 `kernel/` 吗？如果会，快照基线记录了吗？

**答不出第 1、2 题 → 默认不开发。**

---

## 3. 绝对禁止（宪法 §20 与总控 Prompt §44）

1. **禁止虚构「已完成」。**
2. **禁止虚构「测试通过」。**
3. **禁止虚构「接口可用」。**
4. **禁止虚构「许可证允许商用」。**（AGPL / GPL / 未知 / 附加限制 → 一律 `Require Human Review`）
5. **禁止用未经验证的数字作为事实。**
6. **禁止隐藏错误**，包括自己引入的。
7. **禁止为了完成任务而绕过安全机制。**
8. **禁止未经允许删除已有功能。**
9. **禁止偷偷更换技术栈或新增不必要依赖。**
10. **禁止在没跑测试的情况下说「应该没问题」。**

---

## 4. 请示触发条件（只有这些情况才停下来问）

- 关键技术无法实现
- 缺少凭证 / 授权 / 付费资源
- **必须由创始人本人裁决的业务规则**
- 存在破坏现有系统的架构风险
- 法律 / 许可证存在重大不确定性
- **要改动内核的公开接口**

**其余普通问题：自行选择最简单、可靠、可维护的方案继续，不要停下来等。**

---

## 5. 汇报语言要求（面向零基础创始人）

每次汇报必须用普通人能听懂的话说明：

1. **我帮你完成了什么**
2. **你现在的产品可以做什么**（用户视角）
3. **还剩什么**
4. **有没有风险 / 有什么不确定**

**禁止只输出程序员术语。** 技术细节放在后面，先给结论。

---

## 6. 版本与变更记录（宪法 §13）

以下内容**必须版本化**，禁止直接覆盖：Prompt、Agent 定义、DB 结构、AI 工作流、参数与基准数据、本规范集。

**重大变更记入 `CHANGELOG.md`，格式固定：**

```
版本号 · 时间 · 原因 · 内容 · 效果
```

不可回滚的破坏性变更**必须先问**。

---

## 7. 分支与提交纪律

1. **在独立分支开发，`main` 始终可发布。**
2. 不 force-push、不重写历史。
3. 每个阶段独立提交，附验证结果。
4. **禁止提交真实密钥**（宪法 §13 / 安全规范）。用 `.env.example`。
5. 提交信息说明**为什么**，不只说改了什么。

---

## 8. 阶段门槛纪律（落实宪法 §24）

商业模式定稿定义了阶段门槛（见 `../BUSINESS_MODEL_V1.md` 第 6 节）：

```
阶段 0 数据做功  →  门槛：山西包 S+A 级占比 ≥ 70%
阶段 1 标准验证  →  门槛：≥ 3 位从业者愿意引用
阶段 2 工具最小可用 → 门槛：≥ 2 个付费席位
```

**不达门槛不得进入下一阶段，也不得用「顺手把后面的做完」为理由提前开发。**

若创始人要求跳阶段，**必须明确指出这违反了宪法 §24 与 §33**，并说明风险，由创始人明确决定。

---

## 9. 每次开工前的自查清单

```
[ ] 读过宪法 V2.1 的相关条款了吗？
[ ] 知道这个功能属于 L1/L2/L3 哪一层吗？
[ ] 会碰内核吗？碰的话基线快照记了吗？
[ ] 我的改动是最小化的吗？
[ ] 有没有可能在自研已被解决的问题？（禁令 1）
[ ] 有没有把占位数据当事实的风险？（禁令 3）
[ ] 验证命令准备好了吗？
```
