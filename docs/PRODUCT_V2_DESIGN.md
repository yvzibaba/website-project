# PRODUCT_V2_DESIGN — 从"工程师沙盘网站"到"新能源重卡光储充项目投资决策系统"（阶段4 · 第二~五阶段）

> 生成日期：2026-09-09（Asia/Shanghai）
> 上游依据：`docs/MODEL_AUDIT_REPORT.md`（第一阶段审计）、`docs/PROJECT_RULES_V2.md`（宪法）、`docs/V1_FREEZE.md`（冻结清单）、创始人龙卷风裁决（2026-09-09）。
> 核心纪律：**不增加功能，只重构路径与呈现**；**保留现有计算引擎**，不破坏 `MODEL_VERSION` / 黄金样本 / 历史版本；**不制造虚假数据**；**不增加没有商业价值的功能**（开发原则第 4/5/6 条）。
> 本文是**设计蓝图**，非实施。所有涉及改经济模型的项须创始人逐项批准（见 `MODEL_AUDIT_REPORT.md` §7）。

## 定位一句话

V1 是"给工程师看的参数沙盘"；**V2 是"给投资决策者看的新能源重卡光储充项目投资决策系统"**——同一套确定性引擎，三种深度（免费/专业/企业），沿"看到价值→算清价值→买下方案"的商业闭环组织。

**决策优先级（宪法）**：商业闭环 > 用户价值 > 方案质量 > 数据质量 > 自动化 > 效率 > 技术 > 功能 > UI。本设计冲突时一律选更简单/更便宜/可验证/易维护/少依赖人工的一侧。

# 第二阶段 · 产品体验重构（三条用户路径）

现有路由已支撑三条路径的骨架（`src/app/`），V2 **重排与补全**而非新建：

## 路径 A — 游客（未登录）：30 秒看懂价值 → 免费算一次 → 想保存才注册

```
首页(/) ── 30秒价值主张 ──▶ 行业案例(/cases, /industries/[slug])
                                   │  "别人怎么投、投多少、几年回本"
                                   ▼
                          免费沙盘(/sandbox, Level 1 · 10参数)
                                   │  拖几个滑块 → 立即出 NPV/IRR/回收期
                                   ▼
                          生成报告(客户端即时 · 免费·带水印/占位声明)
                                   │  "想保存/导出/对比多方案？"
                                   ▼
                          注册(/register) ──▶ 保存到我的项目(/account/projects)
```

- **关键体验目标**：游客在**不登录**的前提下，5 分钟内完成"改参数→看结果→看懂一句人话结论"。现有 `sandbox-demo.ts`（8 headline 字段）已是 Level 1 雏形（见第三阶段）。
- **诚实边界**：免费报告恒带"占位假设 + E1–E8 简化口径 + 需专业人工确认"声明（`sandbox-report.ts` 已实现，保留）。
- **转化钩子**：保存/导出/多方案对比/AI 解释 → 需登录（现有 `/api/sandbox/projects` POST 已强制登录 401，正确）。

## 路径 B — 企业用户（登录）：画像 → 定制参数 → 生成商业方案

```
登录(/login) ──▶ 企业画像(/enterprise, 5类画像 sandbox-profiles.ts)
                        │  选"物流车队/充电运营商/园区业主/公交市政/财务投资人"
                        ▼
                 定制参数(Level 2 · 40参数工程模式 /sandbox)
                        │  画像注入 presetValues 作起点，用户再精调
                        ▼
                 生成商业方案(/api/sandbox/solution · 服务端现算)
                        │  含企业个性化视角(R7 已实现，只重排不重算)
                        ▼
                 我的方案(/account/solutions) ──▶ 询价/购买(/orders)
```

- **画像现状**：`sandbox-profiles.ts` 5 类画像已建，但审计发现 **F-3（TRANSIT 画像 includeStorage=0 却仍算储能）** 与画像预设含假联动参数（chargerUtilization/equityRatio）。V2 须先修 F-2h/F-3 才能让画像"名副其实"。
- **R7 企业个性化视角**已实现（`sandbox-report.ts` `buildProfileSection`，只挑既有指标卡按画像优先级重排，绝不重算）——**保留，作为商业方案的差异化呈现**。

## 路径 C — 付费用户：购买企业解决方案 → 获得专属模型

```
方案详情(/solutions/[id]) ──▶ 下单(服务端价快照 /api/orders)
                                   │  状态机: PENDING→提交凭证→PAID→解锁
                                   ▼
                          支付确认(后台 /admin/orders/confirm · 当前人工确认)
                                   ▼
                          解锁专属方案(/account/solutions)
                                   │  权限门 entitlement gate(V1_FREEZE 已冻结)
                                   ▼
                          [V2+ 目标] 企业专属模型(Level 3)
```

- **现状**：订单状态机、价快照、凭证、entitlement 门已在 v0.64 冻结并通过 E2E。**真实收款信息/定价是 HUMAN INPUT（创始人待决）**，V2 设计不擅自定价、不接自动支付（高风险，USER 决策风格）。
- **Level 3 企业专属模型**是商业化终点，但按宪法"禁因终局宏大提前做复杂 V1"——**V2 只把路径打通到"购买→解锁既有方案"，Level 3 定制引擎列为 V3+ 路线，不在本阶段实现**。

# 第三阶段 · 沙盘三级重构（保留引擎，只分层暴露）

**铁律**：三级沙盘**共用同一套 `runSandboxModel` 引擎与同一参数目录**（单一真源），区别只在**暴露多少参数 + 呈现深度 + 权限**。绝不 fork 引擎、绝不改 `MODEL_VERSION=1.1.0`、绝不动黄金样本 `scenarios-sml.json`。

| | **Level 1 · 免费版** | **Level 2 · 专业版** | **Level 3 · 企业定制版** |
|---|---|---|---|
| 目标用户 | 普通游客/初步了解者 | 企业工程师/分析师 | 付费企业客户 |
| 参数数量 | **10 核心参数**（业务语言） | **40+ 全参数**（工程模式） | 企业专属预设 + 全参数 + 私有数据 |
| 交互 | 大滑块 + 一句人话结论 | 分组表单 + 高级折叠 | 定制模型 + 多情景对比 |
| 输出 | 即时报告（占位声明） | 完整报告 + 敏感性 + AI 解释 | 商业方案 + 专属溯源 + 交付 |
| 权限 | 无需登录 | 登录 | 登录 + entitlement |
| 时间成本 | **5 分钟** | 30 分钟+ | 项目制交付 |
| 现有基础 | `sandbox-demo.ts`（8 headline，已存在！） | `/sandbox` 全参数（已存在） | `/api/sandbox/solution` + 画像（骨架已存在） |
| V2 工作量 | **小**（把 demo 8→10 参数、补 UI 分层入口） | **小**（工程模式折叠已具备） | **不在本阶段**（列 V3+） |

## Level 1 的 10 个核心参数（业务语言，映射回 40 参数引擎）

现有 `sandbox-demo.ts` 已有 8 个 headline 字段，V2 补 2 个构成"10 核心参数"（映射层 `R8.8a` 已实现，把 ~10 输入映射回 40 参数引擎）：

| # | 用户看到的（业务语言） | 映射引擎键 | 现有? |
|---|---|---|---|
| 1 | 项目地区 | region（电价/光照/补贴默认） | ✅ |
| 2 | 重卡数量 | `project.trucksPerDay` | ✅ |
| 3 | 单车年运营里程 | →`project.chargePerTruck`（里程×电耗折算） | ✅ |
| 4 | 车辆百公里电耗 | →`project.chargePerTruck` | ✅ |
| 5 | 光伏装机 | `project.pvCapacity` | ✅ |
| 6 | 储能容量 | `project.storageEnergy`（÷2h 联动功率） | ✅ |
| 7 | 充电功率(单桩) | `project.chargerUnitPower` | ✅ |
| 8 | 购电价格 | `region.elecPrice` | ✅ |
| 9 | **充电服务费单价**（新增暴露） | `project.chargingPrice` | 引擎已有，Level1 未暴露 |
| 10 | **是否配储能**（新增暴露） | `project.includeStorage` | ⚠️ **须先修 F-2h 才有效** |

> **依赖审计修复**：第 10 项"是否配储能"开关当前是假联动（F-2h）——若现在暴露给用户会造成"关了还在算"的欺骗体验。**必须先接线（F-2h）再暴露**，否则宁可 Level 1 只暴露 9 项。

## 分级入口的 UI 组织（不新增引擎逻辑）

`/sandbox` 页顶部加**分级切换**（免费模式 / 专业模式），免费模式只渲染 10 headline 滑块（复用 `SandboxDemoPanel`），专业模式展开全参数（复用 `SandboxWorkbench`）。两模式**提交同一 layers 结构给同一 `/api/sandbox/*`**，结果逐位一致（因为同一引擎）。

# 第四阶段 · 网站 UI 优化（30 秒看懂价值）

## 首页（`/`）30 秒价值主张审计与优化

**陌生人打开首页，30 秒内必须答出三问**：这是什么？对我有什么用？我下一步点哪？

| 现状问题（待实地核对） | V2 优化方向 | 性质 |
|---|---|---|
| 首屏可能是"平台介绍/案例列表"而非"价值主张" | 首屏第一句改为**结果导向**："3 分钟算清一个新能源重卡光储充项目几年回本" + 一个立即可拖的迷你沙盘/CTA | 呈现 |
| 术语偏工程（NPV/IRR/敏感性/龙卷风） | 面向决策者说人话："多久回本 / 能赚多少 / 最怕什么变量"；专业术语折叠到 Level 2 | 呈现 |
| 缺"免费试算"直达入口 | 首屏放**免登录免费沙盘** CTA（路径 A 起点） | 呈现 |
| 缺信任背书 | 展示"确定性引擎·程序算非AI口算""数据来源可追溯""需专业人工确认"的诚实徽章 | 呈现 |

> **纪律**：UI 优化**只改呈现与文案，不改任何计算/数据**。所有数字仍来自引擎。**不制造虚假案例/客户/数据**（当前全库仅 6 条【DEMO】案例，首页诚实空态优于编造繁荣——保留诚实，不为了"好看"塞假数据）。

## 各关键页优化清单（呈现层，小步提交）

- **沙盘入口（`/sandbox`）**：加分级切换（免费/专业）；免费模式默认，降低首用门槛；修 F-11（硬编码默认值改读单一真源）。
- **报告页**：龙卷风图 → **中国化敏感性呈现**（见第五阶段/§F-7）；保留诚实声明与溯源节；企业个性化视角节（R7）保留。
- **企业页（`/enterprise`）**：5 类画像卡片，选画像即注入 presetValues；须先修 F-3（TRANSIT 矛盾）避免"选了公交画像却算着储能"。
- **方案销售页（`/solutions/[id]`）**：清晰展示"方案含什么/价格/交付物/免责"；价格与收款是 HUMAN INPUT（创始人待决），UI 预留位但**不擅自填价**。

# 第五阶段 · 商业化路径

## 免费 vs 收费边界

| 免费（获客/建立信任） | 收费（企业定制决策软件） |
|---|---|
| 行业案例浏览 | 企业专属模型（Level 3） |
| Level 1 免费沙盘（10 参数） | 私有数据接入 + 多情景对比 |
| 即时报告（占位声明、带水印） | 完整商业方案 + 溯源 + 可导出 |
| 单方案试算 | 专业版全参数 + AI 解释 + 项目制交付 |

## 价格体系（**HUMAN INPUT · 创始人待决 · 本设计不擅自定价**）

- 现有订单状态机已支持"服务端价快照"（v0.64 冻结，E2E 实证 19900.00 快照）。
- **定价、真实收款信息、隐私/条款法务终稿均为创始人拍板项**（USER 决策风格 + V1_FREEZE HUMAN INPUT）。V2 只提供**定价可配置的骨架**（方案表已有价格字段），不硬编码价格、不接自动支付网关。

## 客户画像（对应 5 类沙盘画像）

物流/重卡车队运营商、第三方充电运营商、产业园区/工商业业主、公交/市政集团、财务投资人/基金。**注意**：当前 5 画像 presetValues 均为【示例·待核实】ASSUMPTION（confidence≤50），须专业人工核实后方可用于真实销售——**不得当作已验证的客户数据对外**（宪法数据真实性）。

## 销售流程 / 交付流程（V2 打通到"人工确认"，自动化列后续）

```
获客(免费沙盘/案例) → 留资(注册) → 试用(Level 1/2) → 询价(feedback/orders)
   → 报价(人工·创始人) → 下单(价快照) → 支付凭证 → 后台人工确认(/admin/orders)
   → 解锁方案 → [项目制交付: 定制模型/数据接入/复核报告]
```

- **当前人工确认是正确的 MVP**（宪法：重复>3次才考虑自动化；不接自动支付是高风险项的审慎）。
- **交付流程**中"企业专属模型/私有数据接入"是 Level 3（V3+），V2 交付=解锁既有商业方案 + 人工定制服务。

# 附 · 龙卷风图中国化重构方案（F-7 + 创始人裁决落地）

> 裁决："中国极少龙卷风可以把这个删掉，合理结合中国的实际情况加入重要的影响参数。"

## 呈现层（可立即做，不动模型）

- **删除"龙卷风图/tornado"用户可见文案与隐喻**，改为中国工商业投资语境：
  - 图表名："**关键因素影响力排行**" 或 "**哪些变量最影响回本**"。
  - 形态：保留水平双向条形（本质仍是 ±摆动对 NPV 的影响），但**标题/轴标/图例全改中文商业话术**："涨价 15% → 多赚 X 万 / 电价涨 15% → 少赚 Y 万"。
  - 增加**盈亏平衡视角**：每个关键因素标注"离盈亏平衡还有多远"（决策者最关心）。
- **保留内部标识符**（`computeTornado`/`TornadoRow`/`SENSITIVITY_VERSION`）避免破坏 calcRef 溯源与黄金样本——**内核叫什么无所谓，用户看到的必须是中国话**。
- **修 F-6**：条形图标注的扰动值改为**实际生效（裁剪后）值**，或标注"已裁剪至上限"，消除呈现≠事实。

## 参数层（须创始人批准后接线，属改经济模型）

按中国新能源重卡光储充项目的**真实成本/收益结构**，补齐当前缺席的关键影响参数（这些参数目前假联动 F-2c/e/f/g，须先接入 E 层才能进敏感性扫描）：

| 中国关键参数 | 为何重要 | 现状 | 接线后进入 |
|---|---|---|---|
| **需量电价 demandCharge** | 中国工商业电费=电量电费+**需量电费**，需量是重卡快充场站成本大头 | 假联动 F-2c | E4 购电成本 + 敏感性扫描 |
| **碳价 carbonPrice** | 绿电/储能的环境价值，新能源项目的核心卖点与潜在收益 | 假联动 F-2e | E3 碳收益 + 敏感性扫描 |
| **融资结构 loanRate/equityRatio** | 决定资本金回报（Equity IRR），投资类客户最关心杠杆效果 | 假联动 F-2f/g | 新增融资腿 + 敏感性扫描（高风险·R8.8b 遗留） |
| **上网电价 feedInTariff** | 光伏余电上网收益（仅 exp0>0 激活） | 已接线，但扫描集缺席 | 直接加入敏感性扫描（无需改模型） |
| **峰谷价差 peakValleySpread** | 储能套利核心驱动（中国分时电价政策） | ✅ 已接入(R9.0)且已在扫描集 | 保留 |

> **实施顺序建议**：先做**呈现层中国化 + 修 F-6 + 把 feedInTariff 加入扫描集**（三者不动经济模型，可小步立即做）；需量电价/碳价/融资结构接线属改经济模型，**逐项报创始人批准口径后再做**，每接一项跑黄金样本回归确认不破坏既有 S/M/L 场景。

# V2 不做什么（防范围蔓延，宪法"MVP优先/不增加无商业价值功能"）

- ❌ 不 fork/重写计算引擎（三级共用一套）。
- ❌ 不改 `MODEL_VERSION` / 黄金样本 / 历史版本冻结策略。
- ❌ 不实现 Level 3 企业专属定制引擎（列 V3+）。
- ❌ 不接自动支付网关、不擅自定价（HUMAN INPUT）。
- ❌ 不为"好看"编造案例/客户/数据（诚实空态优于虚假繁荣）。
- ❌ 不擅自接线需量电价/碳价/融资结构（改经济模型须逐项批准）。
- ❌ 不新增与商业闭环无关的功能。
