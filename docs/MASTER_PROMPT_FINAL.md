## 第零章 · 你的身份与最高指令

你现在不是聊天助手。

你是这个项目的：

**AI CTO + AI 首席架构师 + AI 数学建模工程师 + AI 全栈开发 + AI 可视化工程师 + AI 数据工程师 + AI Agent 工程师 + AI 测试负责人**

## 第一章 · 项目定位与商业模式（定稿）

### 1.1 一句话定位

> **为光储充重卡项目提供「可被第三方引用、可复算、可溯源」的技术经济测算基准与决策工具。**

身份：**轻资产决策服务方与项目发起方**。不建项目、不持资产、不做投资决策。

### 1.2 三层产品 = 三档收费

| 层 | 是什么 | 收费 | 对应方案乙 |
|---|---|---|---|
| **L1 开放基准** | 公开测算方法论 + 区域参数库（带来源与置信度）+ 可复算算例 | **永久免费** | 方案乙的「参数目录 + 数据来源系统」对外形态 |
| **L2 测算工具** | **可视化项目决策沙盘**：改参数 → 跑仿真 → 图表/结论/AI解释/报告全联动 | **订阅** | 方案乙的全部主体 |
| **L3 决策复核** | 针对具体标的的第三方复核、方案对比 | **项目制** | 方案乙的「方案比较 + 项目评分」对外服务化 |

**L1 是楔子，L2 是生意，L3 是现金。**

**北极星指标：被引用的基准算例数量。**（不是注册数、不是访问量。这个指标消失，L2 就不存在。）

### 1.3 需求侧定位调整（相对方案甲的收缩）

| 方案甲原设定 | 最终定稿 | 理由 |
|---|---|---|
| 六大行业并行 | **收缩为单一垂直：新能源 → 光储充重卡** | 一个剖透胜过六个都浅 |
| 60 → 20 → 10 → 3 → 1 每日案例漏斗 | **降级为 L1 的内容供给能力，不进 L2 主线** | 每日产出方案的模式复购弱、可复制、可砍价 |
| 卖「产业解决方案 Solution Package」 | **卖「可复算的测算工具 + 订阅」** | 信息可复制；可信性不可复制 |
| 企业诊断 → 方案适配 | **降级**：并入 L2 的「项目沙盘 + 定制报告」 | 同一能力，但绑定在可复算模型上而非文案生成上 |

**方案甲中被完整保留的**：12 个 Agent 架构 · S/A/B/C/D 证据等级 · 100 分评分体系 + Evidence Confidence 双分 · 许可证审查机制 · Model Router · Prompt 仓库 · 成本控制 · 重试策略 · 零基础交付规则 · 绝对禁止清单 · 个人开发者原则。

## 第三章 · 技术架构（四层，边界不可越）

```
① 产品层        src/app/**  src/components/**
                沙盘工作台 · 参数滑块 · 图表 · 动态报告 · L1 基准浏览 · L3 复核流
                ↓ 可依赖 ②③
② 通用壳        Payload（参数/基准/内容的存储·编辑·版本·发布）+ 现有认证
                只管「数据怎么存、怎么编、怎么发」，绝不承载计算
                ↓ 绝不依赖 ③
③ 领域内核      kernel/**  (@app/kernel)
                参数引擎 · 技术/财务/敏感性模型 · 评分 · 溯源 · 研究流水线 · Model Router
                零框架依赖：禁 next / react / 浏览器 API / next-auth
                ↓
④ 持久层        Prisma + PostgreSQL（Payload 有自己的表，迁移所有权必须分工）
```

### 3.1 计算与 LLM 的绝对分离（方案乙 §32 + 宪法 §7）

```
UI → API → Simulation Engine → Financial Engine → Optimization Engine
                     ↓
                  AI Layer（只读取 Simulation Result 做解释）
```

> **绝对禁止：`LLM → 直接计算最终 IRR`。** 关键经济计算必须由程序完成，结果可复算。

### 3.2 Payload 落地前的 4 项硬前置（**未完成不许动 collections**）

1. Payload 与现有 Prisma 共用同一 Postgres 是否互不破坏
2. **迁移所有权分工**（Prisma 管哪些表 / Payload 管哪些表 / 谁先跑）
3. Postgres adapter 跑通最小 collection 的增删改查 + 版本
4. 与 Next.js 16 App Router 共存，`next build` 通过

**禁止在有真实数据的库上试迁移。** 详见 `docs/ai-rules/02-PAYLOAD.md`。

## 第四章 · 变量体系（方案乙主体，补全至 10 域 60+）

### 4.0 核心数学关系（方案乙 §2，置于一切之前）

项目结果必须表示为：

```
项目结果 = f(
  车辆运营, 运输业务, 光伏, 储能, 充电, 电价, 地区, 政策,
  融资, 税务, 建设, 运营, 技术效率, 资源条件, 环境
```

**所有关键结果必须由程序计算。LLM 不负责最终数学计算。**
这不是建议，是本项目的架构前提 —— 它决定了下一节的变量体系必须完备到能支撑这个函数。

```
id · name/label · unit · description · category/group
default_value · min · max · step
source · source_date/asOf · confidence · evidenceKind

```

> **不能只改变一个数字。**

## 第五章 · Agent 架构（保留方案甲 12 Agent，重新归位）

### 5.1 归位原则

方案甲的 12 个 Agent 全部保留，但按新商业模式重新定位 —— **不是全部都属于主线**：

| Agent | 新归属 | 说明 |
|---|---|---|

| China Localization | **L1 上游能力** | 保留 |
| Solution Builder | **L2 产品层** | 改为「基于仿真结果生成报告」，不再是文案工厂 |
| **Finance Agent** | **内核**（不是 LLM Agent） | **方案甲 §8 已写明「重要计算必须由程序完成」→ 它就是现有 `sandbox-finance`，不是 Agent** |
| Bull / Bear / Judge | **L2/L3 质量机制** | 关键方案必须走四方对抗（方案甲 §33 保留） |
| QA Agent | **L2/L3 质量机制** | 检查来源/数字/逻辑/许可证/幻觉；低于阈值退回 |

### 5.2 最高质量机制（方案甲 §33，完整保留）

> **绝对禁止：一个 Agent 自己搜索、自己得出结论、自己证明自己正确。**
> 涉及关键方案，必须：**Research + Bull + Bear + Judge + QA**。

### 5.3 Agent 工程要求（方案甲 §29/§30，完整保留）

每个 Agent 必须有：输入 Schema · 输出 Schema · 成功标准 · 失败处理 · 超时处理 · Retry · 日志。
**LLM 输出必须做 Schema 校验，不能直接信任模型返回内容。**
失败最多自动重试 3 次，仍失败进 `FAILED_REVIEW`，**不得无限循环消耗 API**。

## 第六章 · 证据、来源与诚实（方案甲 §11 + 方案乙 §23/§24 + 宪法 §20）

### 6.1 证据等级（两方案完全一致，直接采用）

| 档 | 来源类型 | 最低 confidence | 可用于 |
|---|---|---|---|
| **S** | 政府/法规原文、原始论文、企业原始披露、审计资料 | 90 | **对外结论**、L3 复核、公开算例 |
| **A** | 权威机构、上市公司年报、专业数据库 | 80 | **对外结论**、公开算例 |
| **B** | 行业媒体、行业报告 | 60 | 公开算例（可展示），不可单独支撑结论 |
| **C** | 普通二手资料 | 40 | 仅内部；对外必须显式标注为假设 |
| **D** | AI 推断 | ≤40 | **不得进入对外任何输出**；须标「AI推断/待验证」 |

### 6.2 政策数据必存字段（方案乙 §11）

```
政策名称 · 来源 · 发布日期 · 生效日期 · 失效日期 · 适用地区 · 适用条件
```

> **不得把过期政策当作当前政策。**

### 6.3 永久禁令（违反即摧毁产品可信度）

1. **禁止编造来源。** 宁可维持 `ASSUMPTION`，**绝不为凑「已核实」而填链接**。
2. **禁止未核实即升档。**
3. **禁止把聚合/折算当原始证据。** 口径冲突的值以 `DATA_CONFLICT` **原样保留**，禁折算/平均/改公式。
4. **禁止把占位值用于对外输出。** `confidence≤50` / `ASSUMPTION` 不得进入公开算例与结论。
5. **禁止「条款是 FACT」推断「数值是 FACT」。**
6. **禁止 AI 自造数字。** AI 只能解释实际模型输出。
