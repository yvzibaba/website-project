## 二、来源优先级与置信度刻度（本批实际使用）

严格按创始人指令第三节执行：S 级（政府/电网/监管/官方统计）→ A 级（权威行业机构/正式披露）→ B 级（专业媒体/价格指数）→ C 级（普通媒体，仅线索）→ D 级（AI 推断，本批未使用）。置信度刻度：S 级现行有效原文 85–95，A 级 70–85，B 级 45–70，C 级 ≤60。

重要模型参数原则上须 S/A 级——本批电价政策类全部达到 S/A；成本类只有 B 级市场指数可用，因此**只记候选、不升级、不接模型**。C/D 级在数据层 schema 中被测试强制禁止 canUpgradeToFact=true。

## 四、口径冲突与差异说明（不强行平均，保留多证据）

1. **峰谷价差：政策比例（相对平段、仅电能量浮动）vs 模型绝对价差（含输配全口径）。** 15号文浮动只作用于电能量部分（输配电价/系统运行费/基金附加不浮动），而沙盘 `region.peakValleySpread=0.6 元/kWh` 是全口径绝对价差。接入时必须用官方比例×电能量基价折算，不能直接拿 1.15×平段全价当 spread。依赖缺口 G1（平段基价）与 G2（输配电价表）。
2. **储能价格：设备采购价（4h，0.529–0.545 元/Wh）vs 模型总造价口径（1.3 元/Wh）。** 设备价不含 EPC/土建/升压站/接入系统；模型口径为全投资单位造价。两者不可直接互换，须建立"设备价→EPC→模型口径"换算（缺口 G8）。
3. **光伏资源：气象辐射区间（理论资源量，2020）vs 利用小时（并网后实际，2025）。** 北部/南部差异大，且实际利用小时受消纳制约（弃光率>10% 调研口径）。接入 `region.pvEquivalentHours` 时应优先实际利用小时口径，辐射区间用于跨区域先验，两者都保留（指令第六节：不平均、说明差异）。

## 八、下一阶段建议（待创始人裁决，本阶段不执行）

1. **补人工缺口优先序**：G1（平段基价）＋G2（需量电价）一次人工即可解锁"电价三参数"的绝对值闭环，是升级 FACT 的最小动作；G3/G8（充电桩、储能 EPC 口径）次之。
2. **接入路径**：若批准接入，建议走既有 `parameter-engine` 逐值 `sources[key].sourceUrl/sourceType/asOf/evidenceKind` 诚实闸门（R8.7 已具备），把候选条目落成带可点击来源的 FACT/区间，而非新造通道；spread 接入须先解决口径冲突①（比例→绝对价差折算）。
3. **地区维度**：山西南北资源差异显著，若后续分市建模，region 维度（太原/大同/朔州/晋中…）在数据层已预留枚举。
4. **阶段3（真实用户验证）**：不依赖本批缺口补齐即可开展；用户是否在意"每条数据可点击溯源"本身就是待验证假设之一。
