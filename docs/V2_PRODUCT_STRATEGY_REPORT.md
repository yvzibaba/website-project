> 命题：把「新能源重卡光储充 AI 平台」从**技术展示网站**升级为**可销售的企业决策软件**
> 依据：`docs/PROJECT_RULES_V2.md`（宪法·最高优先级）、`PRODUCT_SPEC.md`、`ROADMAP.md`（R0–R8.8a 现状）、`docs/PRODUCT_V2_DESIGN.md`（阶段4蓝图）、`docs/HEAVY_TRUCK_CHARGING_LOAD_AUDIT.md`（本轮模型审计）+ 全站页面实地核对

## 结论先行（CEO 一页纸）

**一句话战略判断：这个产品当前不是一个"内容不够多的平台"，而是一个"定位分叉"的平台——它同时想做"泛行业案例方案内容市场"和"新能源重卡光储充投资决策软件"两件事，结果前者是空的、后者是唯一的真资产却被埋没、且被满屏免责声明框成"不能用于决策"。V2 的最高优先级动作是"收敛定位"：把整站主轴押到垂直决策软件，把泛行业内容市场降级为"获客内容层"。**

**三个必须现在拍板的决定（详见 §7）：**
1. **定位收敛**：是否把产品主轴从"六大行业案例→方案市场"收敛为"新能源重卡光储充投资决策软件（SaaS + 项目制交付）"，泛行业内容退居获客/背书层。**（顾问建议：是）**
2. **商业模式形态**：卖"一次性方案文档"（现架构）还是"分层订阅 + 高客单项目交付"（决策软件该有的形态）。**（顾问建议：后者，定价数字仍由你定）**
3. **数据真实化投入**：是否授权把"山西 + 全国核心参数"从 ASSUMPTION 升级为可溯源 FACT（这是从"不能用于决策"变成"可用于决策"的唯一钥匙，管道 R8.7 已建好，只缺权威数值来源）。**（顾问建议：是，且列为 V2 第一优先级资源）**

**北极星指标建议**：`每季度产生 ≥1 个真实付费/意向客户`（对齐宪法第25条"至少一个真实企业验证机会"），而非页面数/功能数/案例数。

## 1. 当前产品定位问题

### 1.1 双主轴分叉，真资产被埋没
`PRODUCT_SPEC` 把产品定义为"每天从全球发现六大行业高价值案例→AI 重构→可售方案"的**内容市场**；而实际唯一能跑、且创始人真正投入的是**新能源重卡光储充沙盘**。首页 Hero 主视觉是"发现全球产业机会"（内容市场话术），沙盘只是第 4 屏一个 banner。结果：**访客第一眼看到的是空的内容市场，真正有价值的决策工具被压在两块"暂无数据"空态之后。**

### 1.2 首页对陌生人 30 秒答不出"对我有什么用"
Hero 强调"AI 拆解、开源匹配、中国本土化重构"——这是**过程/平台自述**，不是**客户结果**。没有产品截图、没有一个可立即体验的价值钩子在第一屏、没有"多久回本/能省多少钱"的结果导向语言。徽章还直接暴露内部里程碑"V1-A·案例→方案→购买最小闭环"。

### 1.3 诚实被写成了"自我否定"（最关键、也最反直觉的定位问题）
宪法要求区分事实/假设、标"需专业人工确认"——这**必须保留**。但当前呈现是"默认数字均为占位假设……**不得作为投资或并网决策依据**"。对一个想买"决策软件"的客户，这句话等于"别信我"。**问题不在诚实，在于诚实的对象错了：我们诚实地声明"数据没核实"，却没有给客户一条"如何把它变成可核实"的路径。** 正确做法是把诚实转化为**可信度分级 + 数据升级路线**（见 §3.4、§6），让"程序算·可溯源·可复算·人工确认"成为对抗"黑箱 AI 报告"竞品的**卖点**而非免责声明。

### 1.4 目标客户未聚焦
5 类画像（车队/充电运营商/园区/公交/投资人）并列，没有"主打谁"。决策软件的 GTM 必须先选**一个**最痛、最愿付费、最易触达的楔子客户（顾问建议：**第三方充电运营商 + 拥有自有车队的物流/重卡运营商**——他们有真实投资测算刚需、决策链短、单项目金额大）。

## 2. 用户购买路径问题

### 2.1 闭环代码全通，但"无货可卖 + 无价 + 无线索捕获"
`ROADMAP` R8.3 已用真 Neon E2E 打通"发布→查看→购买→解锁"。但：
- **无货**：0 份已发布方案，购买按钮无对象。
- **无价**：定价是 HUMAN INPUT，UI 显"定价待定"。
- **无线索捕获**：`/enterprise` 页明确"不收集任何企业信息、不出具诊断结论"，全站**没有任何留资/询价/预约表单**。一个对企业级决策软件感兴趣的访客，除了注册，**无法表达购买意向**。这是购买路径最大的漏斗断点。

### 2.2 免费沙盘到付费之间缺"转化台阶"
现在：免费沙盘（免登录）→ 保存需登录 → 导出方案需 **REVIEWER/ADMIN 角色**（普通用户根本导不出）。也就是说**普通用户走完免费体验后，没有任何"再进一步"的付费动作可做**。缺少 Pro 层的价值台阶（多方案对比、导出 PDF、敏感性/AI 解释、已核实数据包、协作）。

### 2.3 人工确认收款是正确的 MVP，但需显性化"企业采购"形态
转账凭证 + 后台确认对**高客单、低频、对公采购**是合理的；但需要配套：报价单/合同/发票/对公信息的**人工销售流程文档**（不是自动支付网关）。宪法"重复>3次才自动化"——当前一笔都没成交，人工是对的。

### 2.4 购买路径与"决策软件"错配
现架构卖的是"一份方案文档（一次性买断）"。而决策软件的天然商业形态是"**持续使用的工具 + 按需的深度交付**"。把工具（沙盘）免费、把文档（方案）买断，恰好把最该收费的"工具使用权"送了、把最不该是主收入的"文档"当主商品。**这是商业模式与产品形态的根本错配（见 §5）。**

## 3. 沙盘模型问题（承接本轮专项审计）

> 完整技术细节见 `docs/HEAVY_TRUCK_CHARGING_LOAD_AUDIT.md`。此处只讲"作为可售决策软件，哪些问题会让客户不信任/不能用"。

### 3.1 P0-1 场站规模不随车队变化（可信度致命伤）
示范路径 `chargerCount` 从不映射，恒 8 台桩。**20 车、60 车、150 车都用同一个 8 桩场站**。150 车物理上约需 17 台桩、6 小时窗口近峰功率 8,511 kW 已超装机 3,840 kW，模型却照常输出正 NPV。任何懂行的客户（车队/运营商的工程负责人）一眼就能看穿——**这是"演示玩具"与"决策工具"的分水岭问题**。

### 3.2 P0-2 计费需量基准概念错位
`计费需量 = 装机总功率 × 年平均利用率(35%)`——把"装机容量"和"年占空比"相乘冒充"电网最大需量"。量纲成立，物理量错。三个真实情景年负荷率是 9.1% / 22.1% / 53.1%，被一个固定 35% 同时高估小站、低估大站。

### 3.3 P0-3 与现行政策冲突（导致"错误结论"）
经核实，国家及山西政策：**2030 年前，对实行两部制电价的经营性集中式充换电设施用电，免收需量（容量）电费**。当前却把非零需量费计入基线，致小型情景 NPV 误转为 **−153 万**。若客户是合规的集中式充电站，我们给的结论是**错的**（多算了一笔本不该交的钱）。这对"投资决策软件"是原则性问题。

### 3.4 数据全是占位假设（可售性的根本前提缺失）
所有输入 `confidence≤50`、山西无一条已核实 FACT。**决策软件卖的就是"可信的数字"**；在数据真实化之前，任何对外销售都只能是"试用/研究"性质，不能承诺"投资决策依据"。好消息：**升级管道（R8.7 `makeVerifiedFact` + R8.5 溯源写路径）已建好，只差权威数值来源**——这是投入产出比最高的一步。

### 3.5 缺融资腿（投资类客户的核心诉求）
贷款比例/债务现金流/本金利息/DSCR/**Equity IRR**/银行可贷性全部延后（R8.8b）。财务投资人、以及任何要贷款建站的运营商，最关心的就是"资本金回报 + 能不能贷到款"。**没有融资腿，就卖不进"投资决策"场景**。（属改财务核心口径·高风险·须你逐项批准。）

### 3.6 年度代理 vs 逐时模拟（可接受的 V1 简化，但须标注）
无 8760h 逐时负荷、无储能削峰降需量、无补能排队。作为 V1 简化**可接受**，但必须显性标注"年度代理口径"，且不能因此得出误导性峰值结论。

## 4. 页面结构问题

### 4.1 信息架构以"内容市场"为骨架，与真资产错位
首页六段（Hero / 今日案例 / 今日方案 / 沙盘 banner / 企业诊断 / 六步工作流 / 行业浏览）里，**真正能用的沙盘排第 4**，前面两块在空库下都是"暂无数据"。建议 V2 首页重排为"垂直决策软件"骨架：**第一屏 = 结果导向价值主张 + 立即可拖的迷你沙盘/CTA**；案例/行业退到"信任背书与获客内容"位置。

### 4.2 内部黑话系统性外泄（专业度硬伤）
实地核对发现访客可见："V1-A/V1-B"、"R1–R7 主链"、"Research→Bull→Bear→Judge→QA"、"宪法第 X 条"、"里程碑 2 不种子方案"、引擎版本号、以及空态里泄露的开发指令"`?demo=1`"。**这些会把"决策软件"降格成"内部工程 demo"的观感。** 需做一次"对外文案去工程化"清洗（内核标识符保留，用户可见层全改商业话术）——这与 `PRODUCT_V2_DESIGN` 附录"龙卷风图中国化"同源，可合并执行。

### 4.3 沙盘分级入口名不副实
现有切换是"示范项目模型 / 完整参数工作台"，而非 `PRODUCT_V2_DESIGN` 设想的"免费版 / 专业版"。**没有把"深度"与"付费层"挂钩**，也就无法承载 §2.2 的转化台阶。

### 4.4 缺"结果页 → 商业动作"的桥
报告页止步于"生成动态报告 / AI 解释"，没有"下载 PDF（Pro）/ 导出对比 / 预约顾问 / 询价"的商业出口。决策软件每一次算完，都应是一个转化触点。

## 5. 商业模式漏洞

### 5.1 商品形态与收入模型错配（最大漏洞）
现在：**工具（沙盘）免费 + 文档（方案）一次性买断**。决策软件应是：**工具分层订阅（Pro/企业席位）+ 高客单项目制交付（定制模型/数据接入/复核报告）+ 内容/案例作为获客**。把最该持续收费的"工具使用权"免费送、把低频的"文档"当主收入，天花板极低且不可复购。

### 5.2 "泛行业内容市场"模式在当前资源下跑不通
宪法第22条设想"每日 60 候选→1 精品"的自动流水线，但现实是**0 真实案例、0 方案、每日任务(Phase 17)未建、部署(Phase 16)阻塞**。以当前一个人 + 无真实数据源的资源，"六大行业每日产出高质量可售方案"是**不可能完成的承诺**。继续押它 = 持续产出空态页面。

### 5.3 定价缺失导致闭环无法验证
宪法第25条"V1 完成 = 产生至少一个真实企业验证机会/付费"。**没有定价就没有成交，没有成交就无法证明商业模式**。定价是 HUMAN INPUT，但它是解锁整条闭环的开关，建议 V2 早期就给出"定价骨架 + 首批标杆客户优惠价"。

### 5.4 无线索捕获 = 无法销售
§2.1 已述：没有留资/询价/预约入口，销售漏斗从"感兴趣"到"联系"是断的。B2B 决策软件没有线索捕获等于没有销售。

### 5.5 交付能力未定义
若卖"企业定制决策"，交付物是什么、谁来做、SLA 多久、如何复核（宪法第10条"需专业人工确认"意味着**每个对外结论都需人工背书**）——这决定了毛利与可规模化程度，当前完全未定义。

## 6. 下一年产品路线（V2 · 12 个月）

> 原则：对齐宪法"商业闭环 > 用户价值 > 方案质量 > 数据质量"，**单季度单一焦点、每步小步提交、每阶段 STOP 等你复审**；不 fork 引擎、不擅自改财务口径、不编造数据。下列每阶段末尾的"决策门"需你放行才进下一阶段。

### Q1（0–3 月）· 主题：定位收敛 + 可信度地基（让产品"能被相信"）
- **6.1 定位收敛**：确立"新能源重卡光储充投资决策软件"为主轴；泛行业案例/方案降级为获客内容层（保留路由，不再作为首页主视觉）。
- **6.2 首页与落地页重构（仅呈现/文案）**：第一屏结果导向 + 迷你沙盘 CTA；全站去内部黑话（V1-A/R1-R7/宪法第X条/`?demo=1` 等）；"龙卷风图"→"关键因素影响力排行"中国化。
- **6.3 模型 P0 修复（须你逐项批准口径）**：① 车队→桩数/功率缩放规律（修 P0-1）；② 需量基准与"年利用率"解耦 + `gridCapacity` 生效（修 P0-2）；③ 需量费政策情景开关，主情景=0（修 P0-3，直接纠正小型误负）。
- **6.4 数据真实化第一批**：授权通过已建管道把**山西 + 全国核心参数**（电价/光照/需量/补贴/上网价）落成带 `sourceUrl` 的可溯源 FACT；报告输出引入**可信度分级呈现**（FACT/ASSUMPTION 分色 + "已核实 N 项 / 待核实 M 项"）。
- **决策门 G1**：定位与主视觉定稿、P0 修复口径批准、第一批 FACT 数据源确认 → 才进 Q2。
- **交付判据**：陌生人 30 秒看懂"这是什么/对我有什么用/下一步点哪"；沙盘对 20/60/150 车给出**随规模合理变化**的基础设施与需量结论；小型情景不再因政策误算转负。

### Q2（3–6 月）· 主题：商业闭环点火（让产品"能收第一笔钱"）
- **6.5 分层与转化台阶**：沙盘"免费 / 专业(Pro)"分级；Pro 门槛功能 = 保存多方案 / 对比 / 导出 PDF / 敏感性深挖 / AI 解释 / 已核实数据包。
- **6.6 线索捕获**：企业页/报告页加"预约顾问 / 询价 / 留资"表单（最小实现，人工跟进），打通"感兴趣→联系"。
- **6.7 定价骨架 + 首批标杆**：你拍板定价形态与区间；上线 1–2 份**基于已核实数据的标杆方案**（可溯源、人工复核背书），跑通"人工转账→后台确认→解锁"的真实成交（哪怕优惠价/试点价）。
